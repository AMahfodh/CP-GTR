# Glossary: paper notation ↔ code

This maps the notation of the accompanying paper to the code that implements it, so the
two can be read side by side.

| Notation / term | Meaning | Where in code |
|---|---|---|
| TG (type graph) | Fixed vocabulary of node/edge types the whole system is closed over — no rule or parser output may use a symbol outside it. | `TG_NODES` / `TG_EDGES` in `cpgtr/extract.py` and `cpgtr/parse.py` |
| SLG (Semantic Legal Graph) | A typed instance graph over the TG representing the state of a document or a rule's pattern. | `cpgtr.graph.Graph` |
| A, J | Context: reader age, jurisdiction. Deliberately **not** stored as node attributes — kept out of the graph so structural matching stays decidable — and instead evaluated only through a rule's context predicate. | passed as `ctx=(A, J)` through `cpgtr/rules.py`; `CONTEXTS`/`CTX` in `cpgtr/admit.py`, `run_e2e.py` |
| Φ_r(A, J) / phi | Context predicate: whether rule `r` is active for a given age/jurisdiction. | `Rule.phi` in `cpgtr/rules.py`, e.g. `lambda A, J: A < 16 and J == "EU"` |
| L, K, R | DPO (double-pushout) rule anatomy: `L` = left-hand pattern to match, `R` = right-hand pattern after rewriting, `K` = interface (elements preserved, i.e. present in both `L` and `R` under the same id). | `Rule.L`, `Rule.K_nodes`/`Rule.K_edges`, `Rule.R` in `cpgtr/rules.py` |
| NAC (negative application condition) | A forbidden superset-of-`L` pattern; a match is blocked if the NAC can also be found in the host graph. | `Rule.nacs`, `nac_violated()` in `cpgtr/rules.py` |
| Rule modality | additive (adds only) / subtractive (deletes only) / substitutive (both) — determines how a fired rule edits the source text. | `Rule.modality()` in `cpgtr/rules.py`; consumed by `realize()` in `cpgtr/realize.py` |
| ρ (rho) / stratification rank | The smallest rank `k` at which a rule is "repair-typed" (termination-by-construction): elements it creates may only feed rules of strictly lower rank. Computed **globally**, once, over the whole candidate set (not per-candidate — see `⇝` below). | `Rule.rho`; `stratify()`, `r1_satisfied()`, `creation_dependency()` in `cpgtr/certify.py` |
| ⇝ (creation dependency) | `r ⇝ r'` ("r may enable r'"): some element r creates has a type in r''s left-hand side, AND the two rules' guards are jointly satisfiable (can actually both be active for some (A,J)). The relation R2 quantifies over. | `creation_dependency()` in `cpgtr/certify.py`; joint-satisfiability via `jointly_satisfiable()` in `cpgtr/context.py` |
| Minimum feedback vertex set | On a cycle in `⇝` (no valid stratification exists), the *smallest* subset of rules whose removal breaks the cycle — not all rules in the cycle are rejected, only the minimal culprit set. | `_min_feedback_vertex_set()`, `_sccs()` in `cpgtr/certify.py` |
| Context cell | A maximal region of `age × jurisdiction` on which the active rule set `R(A,J)` is constant. Certification quantifies over cells (exhaustive over a fixed domain), not the 3×3 evaluation grid, which only *samples* cells for measurement. | `context_cells()`, `representative_contexts()` in `cpgtr/context.py` |
| CPA (critical pair analysis) | Finds minimal conflicting overlaps between two rules' left-hand sides and checks whether both branches can be reconciled to a common normal form (confluence). | `cpgtr/cpa.py`: `overlaps()`, `critical_pairs()`, `strongly_joinable()` |
| Strong (NAC-)joinability | The confluence criterion CPA checks: a common normal form exists, reached by NAC-consistent derivations, in which every persistent (non-deleted) element from both branches survives and is consistently identified. | `strongly_joinable()`, `_nac_consistent()` in `cpgtr/cpa.py`, using `iso(..., anchor=...)` in `cpgtr/graph.py` |
| NAC-consistent / "closed" NAC | A joining derivation step is safe under future embedding if the NAC it relies on can't be completed by structure disconnected from the matched pattern. Implemented as a conservative, documented *approximation* (structural anchoring), not a full formalization. | `nac_is_closed()` in `cpgtr/rules.py`; `_nac_consistent()` in `cpgtr/cpa.py` |
| Certified normal form / cert | The admitted rule set after passing both certification stages — the thing that gets applied to real documents. | return value `cert` of `admit()` in `cpgtr/admit.py` / `cpgtr/certify.py` |
| Non-termination incident | An **empirical** event: a repair sequence on a real holdout host exceeds `T_max` and is *confirmed* looping via cycle detection. Not a static, admission-time prediction. | `run_repair()`'s `nonterm_incidents` in `cpgtr/eval_repair.py` |
| Stratification rejection | A candidate rule rejected because no valid rank makes it repair-typed (global stratification found it on an unbreakable cycle, or R1 failed outright). | `AdmitLog.strat_rejections` in `cpgtr/admit.py`; `r.rho is None` after `stratify()` in `cpgtr/certify.py` |
| τ (tau) | Age threshold extracted from a statutory provision span (e.g. "under 16"). | `tau` field in `corpus/provisions.json`, produced by `find_tau()` in `corpus/segment_corpus.py` |
| Round-trip / "compliant or flagged" | A realized (edited) document is only reported compliant if re-parsing it and re-running the rule set confirms no rule still fires; otherwise it's flagged for human review rather than guessed at. Its guarantee is upper-bounded by parser recall: a construct the parser never recovers is invisible to both the initial parse and the re-parse. | `round_trip()`, `process_document()` in `cpgtr/realize.py` |
| Stage-1 extractor | LLM step that turns a statutory provision span into a candidate rule (JSON-constrained to the TG). Real mode calls an OpenAI-compatible chat endpoint; the provider and model are selected in `cpgtr/llm.py`. | `cpgtr/extract.py` + `cpgtr/llm.py`; offline stand-in is `cpgtr/library.py: synthesize()` |
| CP-GTR-Detect | The detection-only baseline arm of the compliance table (Table 5): identical certified rule set/parser/corpus as CP-GTR, but rules only *flag* matches (never rewrite); the flagged document is handed to the LLM to regenerate. Isolates repair-vs-detection. | `flag_violations()`, `cpgtr_detect_repair()` in `run_e2e.py` |
| SLG* / target normal form | The graph state after exhaustively applying the certified rule set for a given context — a document with no remaining applicable rule. | `normal_forms()`, `normalize()`, `normalize_trace()` in `cpgtr/rules.py` / `cpgtr/realize.py` |
